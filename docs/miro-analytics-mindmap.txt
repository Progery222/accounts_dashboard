Аналитика
	Зачем нужна аналитика
		Операционный контроль
			Единая картина по всем аккаунтам и платформам
			Рост и падение просмотров, подписчиков, постов за день, неделю, месяц
			Быстрый поиск отстающих аккаунтов и платформ
		Решения по контенту
			Топ постов — что набирает просмотры
			Хештеги и корреляция с охватом
			Лучшее время публикации — часы и дни недели по МСК
		Мониторинг инфраструктуры
			Статус автообновления — идёт, завершилось, ошибка
			Посты пропали со скрапа — удаление или сбой парсинга
			Дельты по владельцам и профилям — срез по командам и нишам
		Трансляция и TV-режим
			Живой график Pulse за 24 часа для экрана в офисе
			Прирост за календарный день по платформам
	Метрики и зачем они нужны
		Главный экран
			Сводные KPI
				Просмотры — главный показатель охвата
				Подписчики — рост аудитории
				Лайки — вовлечённость где доступно
				Посты — объём контента в базе
				Клики — переходы по ссылкам из bio через Links
				Аккаунты — масштаб фермы
				Текущее значение плюс дельта за период один, семь или тридцать дней
			Разбивка по платформам
				TikTok, Instagram, YouTube, X, Threads, Telegram, Facebook, Rumble, Reddit
				Доля, число аккаунтов, просмотры, дельта просмотров
			График Pulse за сутки
				Ступеньки каждые тридцать минут по МСК
				Скачки после автообновления — реальный прирост после скрапа
				Дельта за день над графиком — рост с полуночи МСК
				Линии по платформам — прирост просмотров за день
			Список аккаунтов
				Просмотры, подписчики, посты, дельты, статус доступности
				Фильтры — платформа, профиль, владелец, скрытые, сортировка по дельте
		Вкладка Аналитика
			Топ постов
				Просмотры, лайки, комментарии, репосты
				ER — engagement rate от просмотров
				Дельта за один, семь или тридцать дней от снимка поста
				Сортировка по просмотрам, лайкам, дельте
				Фильтры — платформа, аккаунт, профиль, владелец, минимум просмотров, хештег
				Режим пропали со скрапа
			Insights
				Сравнение платформ — средние просмотры, лайки, ER
				Топ хештегов — частота и средние метрики
				Лучшее время — часы и дни недели по МСК
		Уровень аккаунта и поста
			Карточка аккаунта — история снимков, посты, ручной refresh
			Дневной снимок аккаунта — основа дельт
			Дневной снимок поста — основа дельт в аналитике
	Как собирается информация
		Общий пайплайн
			Триггер
			Скрапер платформы
			Обновление аккаунта и постов
			Снимки
			Точка Pulse
			Отображение в UI
		Триггеры обновления
			Ручной — кнопка у аккаунта или обновить все
			По расписанию — APScheduler, интервал или фиксированные часы
			Импорт CSV — исторические снимки
		Скрапинг по платформам
			Playwright-воркеры — TikTok, Instagram, Facebook, Threads, X, Telegram, Rumble
			HTTP и API — YouTube Data API, Telegram API
			FlareSolverr — Rumble, обход Cloudflare
			Apify — опциональный fallback
		Запись в базу
			Поля аккаунта — подписчики, просмотры, лайки, посты, аватар
			Посты — внешний id, метрики, URL, превью, дата, хештеги
			Снимок перед перезаписью — раз в день
			Синхронизация постов — новые, обновлённые, пропавшие
		Агрегаты и дельты
			Снимки аккаунта и поста — уникально по дате
			Точки Pulse — каждые тридцать минут сумма просмотров в БД
			Точки после автообновления — scheduler, refresh, refresh_all
			Прирост по платформам за прогон
		Клики по ссылкам
			При refresh — запрос к Links API, счётчик кликов
	Что нужно для сбора статистики
		Инфраструктура
			Сервер Docker — backend, postgres, frontend через nginx
			APScheduler в backend
			FlareSolverr для Rumble
			Xvfb или RDP — headed-браузер для антибота на Mobile Farm
		Данные и доступы
			Аккаунты в БД — username и platform
			Сессии браузера — cookies и профиль Chromium
			API-ключи — YouTube, Telegram, Apify, Links
			Логины платформ в env где требуется
		Настройки в интерфейсе
			Расписание автообновления — вкл, интервал или часы
			Фильтры автообновления — платформы, профили, владельцы, скрытые
			Период дельт в списке — один, семь или тридцать дней
		Качество данных
			Регулярный refresh — без него дельты и Pulse не растут
			Рабочие сессии — иначе скрап падает или отдаёт нули
			История снимков — для дельт за неделю и месяц нужны старые снимки
	Как часто актуальна статистика
		В интерфейсе без refresh
			Дашборд — при открытии и после завершения автообновления
			Статус обновления — опрос примерно каждые тридцать секунд
			Pulse-ступеньки — каждые тридцать минут по МСК даже без скрапа
			Данные аккаунтов и постов — только после ручного или авто refresh
		Автообновление
			По умолчанию выключено
			Режим по времени — слоты шесть, двенадцать, восемнадцать, ноль часов МСК
			Режим интервал — например каждые шесть часов
			После прогона — новая точка Pulse и обновлённые счётчики
		Ручное обновление
			В любой момент — актуально сразу после завершения
			Пакетное обновление — примерно одна-три минуты на аккаунт
		Дельты и периоды
			Один день — снимок вчера или начало суток для Pulse
			Семь дней — снимок аккаунта неделю назад
			Тридцать дней — снимок аккаунта месяц назад
			Без снимка — дельта равна всему текущему счётчику
		Практический вывод
			Pulse обновляется каждые тридцать минут плюс скачки после refresh
			Просмотры и посты — на момент последнего успешного refresh
			Четыре раза в сутки — свежесть до шести часов, ручной refresh — сразу
